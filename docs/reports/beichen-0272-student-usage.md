# 北辰 0.27.2：学生端每模型消耗补全

## 问题

老师反馈学生端“没有显示每个模型的积分消耗”。实际页面已有“本月已用 X 积分”，但：

1. 只统计已成功结算的 charged；待核/在途不落到模型维度，只有待核的模型会显示成“本月未使用”。
2. 同一模型跨项目、跨 Key 被拆成多行，没有合计。
3. 没有调用次数；0 积分但有调用的模型和完全没用过的模型无法区分。
4. 个人用量页的“按模型用量”依赖 Key 分片，Token/缓存命中率取不到时只能显示“—”。

## 改动

### 模型广场

卡片和详情统一按模型 ID 聚合：跨项目、跨 Key 合并已扣积分与调用次数。显示规则：

- 有已结算积分：`本月已用 12.5 积分 · 3 次`。
- 0 积分但有调用：`本月 0 积分 · 3 次（未结算/待核或免费）`。
- 没有调用：`本月 0.000 积分 · 0 次`，不再显示“本月未使用”。

页面顶部说明“只统计已成功结算”；项目层 pending 不为 0 时提示“有 X 积分在途/待核，尚未分摊到具体模型”。

### 个人用量页

保留原有“按模型用量”，增加“调用次数”列；新增“按模型合计”，同一模型跨项目/Key 合并为一行，显示已扣积分、调用次数、Token、缓存命中率。取不到的字段显示“—”，不用偏小值冒充总数。底部按 Key 明细也补了调用次数。

“今天/全部”范围下积分、次数、Token 统一显示“—”，并保留接口只返回本月汇总的说明，不拿本月数据冒充其它范围。

### 聚合口径

积分按 0.001 的整数拆分累加，避免浮点误差；模型 ID 统一小写；calls 缺失按 0（Go 端 omitempty）；Token 只有所有分片都提供才合计；缓存命中率按调用次数加权，缺片显示“—”。

## 验证

前端 vitest 47 个测试文件、343 项通过；vue-tsc --noEmit 通过。新增 studentUsage 工具、模型广场、个人用量页用例。未改后端、数据库或计费口径。

## 仍缺的后端字段

分模型待核/在途：`UsageSlice` 只有 id/name/credits/calls，pending 只到项目和 Key 层。要让某模型显示“X 积分待核”，需要后端按 `gateway_calls.model_id` 聚合待核记录。
分模型 Token/缓存命中率：学生用量接口目前不返回 tokens/input_tokens/output_tokens/cache_hit_rate，页面只能显示“—”。
