# Nebula 生成式品牌素材

- 使用内置 `image_gen` / imagegen 技能生成；工具没有提供可手动设置的模型参数，未声称特定模型版本。
- 采用几何 N 字标与连接端点，体现 AI 模型接入；深紫背景与浅紫主体适配星空紫界面。
- 原图：`frontend/public/assets/brand/nebula-n-generated.png`。
- 正式页面素材：`nebula-n-128.png`；浏览器图标：`nebula-n-32.png`、`nebula-n-192.png`；Apple 图标：`nebula-n-180.png`，均位于同一目录。
- 尺寸衍生图仅通过 Chromium 按目标尺寸导出，保留原生成图形，不进行手绘或矢量重描。
