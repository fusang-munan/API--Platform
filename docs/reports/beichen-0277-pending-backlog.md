# 北辰 0.27.7：存量待核回放与批量结算

## 功能

教师端供应商对账页新增“存量待核回放”卡片：

- 只读回放：显示该供应商全部待核、本批最早 200 笔、exact/narrow/wide/unknown 分类、可自动结算数、最大误差、预计上游金额和样本。
- 批量结算：确认弹窗后，只结算本批可自动项；宽区间只重算预留，不扣款；无价格记录保留。
- 预览令牌：SHA-256 绑定供应商、offset、limit、全量有序待核 ID、本批分类和报价；待核集合任何变化（包括新增无价格记录）都会 409，必须重新回放。
- 分页：limit 默认 200、最大 500，报告 next_offset；首页无自动项时可查看下一批。
- 权限与缓存：教师专用；200/403/409/422 均带 `Cache-Control: private, no-store`。

## 结算口径

- 自动结算沿用 0.27.5 的金额区间和每学生历史先验；扣款不超过上界。
- wide 行按当前上界和学生剩余额度重算 `unresolved_credit_milli`，不扣款；unknown 无价格保持原预留。
- 每笔在独立事务中先锁学生、再锁调用；重复或并发确认不会双扣。
- 失败行完整回滚，其他行继续；重新回放可补结。

## 验收

- 独立复核两轮：第一轮发现无价格记录未入令牌、403 无 no-store、固定 200 笔、确认非弹窗；返工后五项 PASS，wide 预留 1→28 的账务细节再返工后 PASS。
- PostgreSQL：回放不写 56 张表；narrow 实扣 0.01562、wide 预留 28、无价格 unknown 保留；201 笔 200+1 分页；令牌篡改/跨页/新增 409；并发/重复不双扣；失败行回滚；教师/学生权限与缓存头。
- Go build/vet、六包 866 个测试、独立空库全量 1101 个测试通过；前端 352 项与类型检查通过。

## 残余风险

- 每批最多 500 笔；如果最早一批全部不可自动结算，需要手动翻下一批。
- 令牌校验与逐笔扣款分属不同事务；校验通过后新进入的待核依靠行锁和报价复核保护，不会重复扣。
- 生产真实存量规模和浏览器视觉未在本机验收范围内。
