# 北辰 0.26.2：学生模型广场按可用性分组

## 问题

学生 Key 已授权 9 个模型，但当前四把上游 Key 只能探测到其中 4 个：
claude-opus-5-5、deepseek-v4.1-flash、gpt-6.2-astra、gpt-6.2-sol。
另外 5 个是历史授权，已经没有上游线路，却在模型广场的“可用模型”里显示为维护中，
并附带“协议不匹配 / 请切换协议”。DSH 的 /v1/models 默认只返回可调用模型，
因此 DSH 只显示 4 个，和学生广场的 11 个看起来不一致。

## 修正

- 模型广场按“可调用 / 待验证 / 维护中 · 历史授权 / 可添加”分组，默认只显示可调用。
- 计数改为“当前 Key 已授权 N · 可调用 X · 待验证 Y · 维护中 Z · 可添加 W”。
- 维护中的历史授权不再显示协议不匹配或“请切换协议”，改为“历史授权 · 当前无上游线路”及具体原因。
- 维护中分组提供“清理全部不可用授权”，批量调用已有移除接口；确认后刷新 Key 和模型列表。
- 增加说明：DSH/Codex 的 /v1/models 默认只返回可调用模型，旧授权不会出现在客户端选择器里。

## 验证

- 前端 46 个测试文件、327 项通过；typecheck、build 通过。
- 新增默认 4 个可调用、5 个历史授权、批量清理和计数文案用例。
